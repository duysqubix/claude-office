# Asset catalog

Every 3D model in Claude Office: who builds it, what it is, and in what order. The
browsable version is `http://127.0.0.1:4777/catalog.html`, generated from the models
themselves (`npm run catalog`).

Priorities: **P0** the game uses now (replaces procedural geometry) · **P1** richer office ·
**P2** fun extras for future gameplay. Work P0 → P1 → P2. Read `docs/BLENDER.md` (pipeline)
and `docs/ART-REFERENCE.md` (Wobbly Life look) first.

## How it fits together

```
assets/blender/lib.py                 shared helpers (owned by Claude Monet: import it, don't edit it)
assets/blender/<category>/<id>.py     one deterministic build script per model, defines build()
assets/catalog/<id>.json              sidecar metadata, written by the model's artist
client/public/models/<id>.glb         export (lib.finalize)
snaps/blender/<id>.png                preview render (lib.finalize); thumbnails are derived from it
client/public/models/catalog.json     generated by `npm run catalog` (dims, tris, bytes from the GLB)
```

Build one model headless:
`/Applications/Blender.app/Contents/MacOS/Blender --background --python assets/blender/build.py -- <id>`

### Rules every artist follows

- **ids are global and unique** (the list below is the registry). Lowercase snake_case.
- **One joined mesh per model** with named materials. Materials the game recolours are
  listed as `tintable` in the sidecar; use these names exactly: `Skin`, `Shirt`, `Pants`,
  `Shoes`, `Hair`, `Accent`, `Seat`, `Screen` (emissive; the game swaps its texture).
- Parts that animate stay **separate named nodes** inside the GLB (e.g. `DoorL`/`DoorR`,
  `HourHand`/`MinuteHand`, `Lid`, `Drawer1`).
- **Pivot** at the floor-contact point (wall items: the wall-contact point; worn items: the
  attach point named in their sidecar `anchors`). **Front faces Blender -Y** (= three.js +Z).
- Budgets: small ≤ 3k tris, medium ≤ 8k, large ≤ 15k, characters' parts ≤ 2k each.
  Baked AO at 256² (small) / 512² (medium/large), exported as WebP. Keep every GLB under
  ~250 KB unless there's a good reason.
- Sidecar `assets/catalog/<id>.json`:
  ```json
  { "id": "office_chair", "name": "Office chair", "category": "furniture",
    "artist": "Claude Monet", "priority": "P0", "status": "done",
    "description": "Wheeled swivel chair with puffy cushions",
    "tags": ["seating", "desk"], "tintable": ["Seat"],
    "anchors": { "seat": [0, 0.45, 0] } }
  ```
  `status`: `wip` while iterating, `done` when exported and previewed. Anchors are in
  three.js space (metres, Y up, +Z front).

Categories: `furniture`, `appliance`, `decor`, `desk-item`, `food`, `building`, `outdoor`,
`plant`, `character-body`, `character-hair`, `character-hat`, `character-face`,
`character-accessory`, `character-held`, `character-outfit`, `pet`, `preset`.
