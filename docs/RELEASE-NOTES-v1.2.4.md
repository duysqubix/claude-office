**More room to talk: the chat panel can be as wide as you like.**

## New in v1.2.4

**A wider chat:** drag the chat panel's left edge to the left for more room to read and type. A grip shows when you hover. Double-click the edge to switch between the usual width and wide, or focus it and use the arrow keys. Your browser remembers the width.

## Upgrade
```bash
git pull && npm install && npm start
```
